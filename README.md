# ohjk26

Tämä repositorio pitää sisällään html- ja markdown-tehtävät.

Tee kaikki tehtävät.

Tehtävät palautetaan moodlesta linkattuun github-classroomiin käyttäen github desktop -sovellusta.

Tee:

* html-tehtävät omalla koneellasi käyttäen tekstieditoria (esim. vs code) ja haluamaasi selainta,
* markdown-tehtävät omalla koneellasi käyttäen tekstieditoria (esim. vs code) tai github.com:in sisäänrakennettua tekstieditoria.

## Työkalut

Tarvitset tehtävien tekemiseen versionhallinnan työkalun ja tekstieditorin:

* vscode (tekstieditori)
* github desktop (versionhallinnan työkalu, jonka avulla tehtävät palautetaan)

Ohje työkaluihin ja linkit työkalujen lataamiseksi:

* [ohjelmat](./harjoitukset/01-ohjelmat/01-ohjelmat.md)
